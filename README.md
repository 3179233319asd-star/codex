# 此间的小站

以动态黑洞开场的中文个人网站。首页只有一屏：实时 WebGL 星空、简短介绍、顶部个人内容入口和底部圆角工具栏。作品、随记和关于点击后在阅读面板中打开；目前收录实际完成的视觉实验「事件视界」和一篇制作记录。场景不使用背景照片、视频或图片贴图，吸积盘细丝、星点、光环和湍流由代码生成。

界面采用正常字号、圆角按钮和轻透的深色面板。字体优先使用 `ui-rounded` 和操作系统原生字体，以本地打包的 Noto Sans SC 400 / 500 字重作为中文回退。首页不滚动；阅读面板在较矮的屏幕上内部滚动，手机保留全部个人内容入口和星空控制。

「此间」是暂用站名。姓名、首页介绍、GitHub 链接、自述、作品说明和随记正文集中在 `src/content.js`，可直接替换为自己的内容。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
cd /workspace/codex
npm ci
npm run dev -- --host 0.0.0.0 --port 4173 --strictPort
```

```sh
npm run build
npm run preview -- --host 0.0.0.0 --port 4173
```

## 交互

- 个人内容：顶部「作品」「随记」「关于」打开原生 `dialog` 阅读面板。面板内用分段标签切换内容；标签支持左右方向键、`Home` 和 `End`，`Esc` 或关闭按钮返回首页并恢复焦点。
- 作品：点击「事件视界」或「制作记录」以作品面板替换个人面板，关闭后返回作品页；点击「进入星空」进入沉浸模式。
- 随记：仅在阅读面板内展开全文，可在正文末尾收起。
- 关于：展示个人介绍与 GitHub 链接，手机上也可访问。
- 指针移动：轻微视差。
- 暂停 / 继续：冻结和恢复场景时间。
- 场景设置：调整时间流速和光芒强度，恢复默认值。
- 沉浸模式：隐藏网站文字与导航，完整观赏场景；按 `H` 切换，`Esc` 返回。
- 阅读面板打开时停用场景快捷键；焦点位于按钮、链接或输入控件时，空格保留控件原有行为。
- 打开个人内容或作品面板后，场景自动暂停；关闭阅读面板后按原先的播放状态恢复，保留手动暂停的选择。
- 系统的「减少动态效果」设置会默认暂停动画，并响应运行期间的偏好变化；仍可手动播放。

## 结构

- `src/blackhole.frag`：引力光线弯曲、三层吸积盘的差速旋转和湍流、外层气体散射、尘埃、星空与远处星系。
- `src/space.js`：WebGL2 渲染、辉光后期处理、动画时钟、尺寸适配和 Canvas2D 降级。
- `src/content.js`：站名、个人介绍、链接、作品和随记内容。
- `src/main.js`：一屏首页、阅读面板、键盘标签切换、文章展开和场景交互。
- `src/style.css`：响应式样式。
- `tests/browser-smoke.mjs`：浏览器功能验证，使用云环境中的 Playwright 和 Chromium。
- `design-qa.md`：参考图对照和浏览器验证记录。

中文回退字体和图标通过 npm 安装并随构建打包，运行时无需外部字体服务。画面是对参考图的程序化视觉还原，光学模型作了简化，适合视觉展示。

黑洞按参考图保留吸积盘的倾角：主亮带略低于圆心，前景尘埃遮住下半环的上缘，上下影像通过独立光路形成。两侧后方气体沿内凹曲线展开，前景盘保留自己的透视和遮挡。三层独立纹理、差速旋转、断续长丝和局部暖散射共同产生气体流动；光线微分按实际投影过滤过细的纹理，避免倾斜盘面出现点阵和织纹。较克制的辉光保留亮度层次。Canvas 回退保留同样的透视关系，以更简单的光丝提供兼容效果。

最新首页截图见 `test-results/blackhole-latest-desktop.png` 与 `test-results/blackhole-latest-mobile.png`，前后对照见 `test-results/blackhole-latest-before-after.jpg`，交接局部与参考图对照见 `test-results/blackhole-latest-junctions.jpg`。这些截图仅是开发验证产物，不参与网站渲染；参考图的单根光丝和随机尘埃图案不会逐像素复制。渲染检查运行 `node tests/render-smoke.mjs`，结果写入 `test-results/render-report.json`。
